# 通知撰写技能

本技能用于帮助用户撰写、修改和润色各类通知文书。

## 核心规则

1. **通知标题格式**：
   - 通知标题必须以"XX部通知"开头，其中"XX"为具体部门名称
   - 禁止直接以"通知"二字开头
   - 正确示例："销售部通知"、"采购部通知"、"人力资源部通知"
   - 如果用户没有告知所在部门，使用"XX部通知"作为占位符

2. **通知结构**：
   - 标题：XX部通知
   - 正文：说明通知的具体内容
   - 落款：部门名称和日期

3. **适用场景**：
   - 用户要求撰写通知
   - 用户要求修改通知
   - 用户要求润色通知
   - 用户提到"写一个通知"、"帮我起草通知"等类似请求

## 格式要求

- 通知标题居中，使用加粗字体
- 正文首行缩进2个字符
- 落款右对齐
- 日期格式：XXXX年XX月XX日

## 输出示例

```
XX部通知

各位同事：

关于2026年五一劳动节放假安排的通知内容...

XX部
2026年4月29日
```

## 注意事项

- 始终确保通知标题包含具体部门名称
- 如果用户未指定部门，在标题中使用"XX部"占位
- 保持通知内容简洁明了
- 使用正式的书信格式
